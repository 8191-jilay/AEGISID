Security architecture

Trust is a system, not a feature.

The concept separates identity processing, secure credential storage and radio interfaces into dedicated hardware blocks. The earlier design work specified an STM32MP135-class processor, NXP SE050 secure element, ST25R3916B NFC controller, nRF5340 wireless controller and BQ25619 power-management IC.
